## 获取数据（基础功能）

### 操作步骤

1. 在控制栏选择 **数据来源**（币安 Binance / OKX）
2. 输入 **交易对**（如 `BTCUSDT`、`ETHUSDT`）；周期固定为 **1h**
3. 点击 **「获取数据」** 按钮
4. 图表开始刷新，状态栏显示当前数据来源和交易对信息；等待状态栏确认数据获取成功

### 数据来源说明

| 来源 | 说明 |
|------|------|
| **币安 Binance** | 公共 REST 行情，无需交易所 API Key；优先走 `data-api.binance.vision`，国内可直连；本版本仅使用 1h 周期 |
| **OKX** | 公共 REST 行情，无需交易所 API Key；国内网络通常需要代理；本版本仅使用 1h 周期 |

> 交易对在界面统一使用 Binance 风格（`BTCUSDT`）；OKX 适配器会自动转换为 `BTC-USDT`。

### 刷新机制

- 点击「获取数据」后，程序以设定间隔（默认 **1 秒**）持续从数据源拉取最新 K 线
- 新数据到达后自动更新图表（蜡烛图 + EMA20 叠加线）
- 最新未收盘 K 线以**浅色空心蜡烛**显示，不参与 AI 分析
- **切换交易对 / 周期后，刷新自动停止**，需重新点击「获取数据」才会恢复拉取
- 每次点击只请求一次；网络失败时状态栏提示，不会自动重试

### 连接失败处理

- **数据源未连接**：点击「获取数据」后状态栏提示"数据源未连接，请先切换数据来源"
- **币安接口 HTTP 451**：当前网络被限制，开启代理后重启程序
- **OKX 连接超时**：国内网络需要代理；`启动PA_Agent.bat` 会自动检测本机 7897 端口代理
- **交易对无效**：输入框下方显示黄色提示，检查是否写成 `BTCUSDT` 这类完整交易对
- **没有该交易对**：状态栏会显示交易所返回的错误信息（如币安/OKX 无此交易对）

### 切换数据来源

- 切换数据来源时，图表自动重置，旧数据源断开连接
- 切换交易对 / 周期时，图表自动重置，刷新停止，需重新点击「获取数据」
- 切换期间若有分析正在进行，分析将被取消

### 注意事项

- 交易对支持 `BTCUSDT`、`BTC-USDT`、`BTC/USDT` 等写法
- K 线数据不足时，图表缓冲区需要数秒填满，期间状态栏提示"数据不足"
- 本版本仅使用现货 USDT 交易对；合约（SWAP）暂不支持
- 程序不会自动轮询；每次点击「获取数据」只请求一次
